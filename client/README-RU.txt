Автообновление Lead-Partner · Общая для Windows

Если обновлятор уже установлен и иногда появляется чёрное окно

Распакуйте новый архив установщика и один раз снова запустите
Install-AutoUpdate.bat от прежнего пользователя Windows. Сохранённая папка
расширения выбирается автоматически. После «Готово» установщик можно закрыть.
Существующая задача обновления будет переведена на запуск без консольного
окна; прежняя папка расширения, подготовленные обновления и восстановление
сохраняются. Обычное обновление расширения не меняет установленный обновлятор.

Установка на каждом компьютере один раз

1. Распакуйте весь архив установщика в обычную папку.
2. Дважды нажмите Install-AutoUpdate.bat под тем пользователем Windows,
   который работает с расширением. Запуск от администратора не требуется.
3. Выберите уже установленную распакованную папку «Lead-Partner · Общая»:
   ту же папку с manifest.json и ROOTRELEASE_FILES.json, которую вы ранее
   загрузили в браузер. Папка должна содержать полный исходный выпуск.
   Не выбирайте папку профиля браузера, ZIP-архив, Админ или Захар.
4. После сообщения «Готово» установщик можно закрыть. Распакованную
   временную папку установщика можно удалить; папку расширения оставьте.

Расширение должно быть заранее установлено как распакованное. Установщик
сам не устанавливает его в браузер и не меняет его папку или идентификатор.
Если расширение перенесли, снова запустите установщик и укажите новый
полный путь явно. Повторный запуск без параметров сохраняет прежний путь.
Путь нельзя менять, пока есть ожидающее обновление или восстановление.

Работа обновлений

Задача Windows «LeadPartner-Common-AutoUpdate-<SID пользователя>» запускается
от текущего пользователя при входе в Windows и каждые 15 минут, пока он вошёл.
Суффикс SID разделяет задачи разных учётных записей Windows на одном ПК.
Файлы обновлятора находятся в %LOCALAPPDATA%\LeadPartnerUpdater\Common.
Задача запускает локальный LeadPartner.Runner.exe без аргументов. Он создаёт
фоновый процесс проверки без консольного окна и ждёт его завершения.
Программа собирается установщиком из приложенного исходника SilentRunner.cs
системными средствами Windows. Окно ручной установки показывается один раз;
регулярные проверки и проверки при входе в Windows выполняются без него.
Обновления берутся из публичного репозитория:
https://github.com/mirher228-droid/lead-partner-updates
Пароли, токены GitHub, права администратора и новые разрешения расширения
для работы обновлятора не нужны.

Пока браузер запущен, обновление только скачивается и подготавливается.
Для применения полностью закройте браузер, включая его фоновые процессы,
и дождитесь следующей проверки (до 15 минут). Затем откройте браузер.
Обновлятор сам не закрывает браузер. Не удаляйте и не устанавливайте заново
расширение при обычном обновлении: сохраняйте его прежнюю папку.

Для ручной установки с известным путём откройте Windows PowerShell:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-AutoUpdate.ps1 -ExtensionPath "C:\Extensions\Lead-Partner-Common"
Параметр -StartNow после успешной установки запускает зарегистрированную
задачу сразу; обычная установка ждёт ближайшего запуска по расписанию.

Если проверка не срабатывает, откройте Планировщик заданий и проверьте
«LeadPartner-Common-AutoUpdate-<SID пользователя>». Локальные status.json и updater.log
в папке обновлятора помогают понять результат последней проверки.
Если Windows или политика организации запрещает задачи/PowerShell,
передайте точное сообщение ответственному за компьютер. Установщик
не обходит ограничения организации и не запрашивает повышение прав.

Удаление автообновления

Запустите Uninstall-AutoUpdate.bat из архива установщика или из папки
%LOCALAPPDATA%\LeadPartnerUpdater\Common от того же пользователя Windows.
Удаляется только задача и известные файлы обновлятора/config.json.
Само расширение, авторизация и его настройки сохраняются. Резервные копии,
журнал восстановления, подготовленное обновление и логи остаются в папке
обновлятора для восстановления. Не удаляйте их во время незавершённого
обновления. Повторная установка возможна тем же установщиком.

Только для автономных тестов разработчика: -NoRegisterTask вместе с
-InstallRoot %TEMP%\LeadPartnerUpdater-Test-<32-символьный GUID>\Common.
Тестовый режим не создаёт задачу и не запускает проверку обновления.
