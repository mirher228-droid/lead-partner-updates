# Итог автономной проверки

Это исторический протокол первого этапа. Расширенный этап и настоящий пятичасовой
прогон завершены; актуальные результаты и ZIP описаны в
`reliability-extended-validation.md`. Указанные ниже ZIP и хеш относятся к первому этапу.

Исходная версия: Common 1.2.50, HEAD
`0cdd091e417268cfe1bd5df7a00ab71d9e23ad93` плюс локальные исправления надёжности.
Среда: Python 3.12.14, Node.js 24.22.1, Chromium в Linux. Сторонние Python/Node
пакеты не устанавливались.

| Проверка | Итог |
| --- | --- |
| `node --test` | exit 0; 66 записей test runner, 66 passed, 0 failed/cancelled/skipped/todo. В число входит контейнер браузерной группы |
| Реальная панель в Chromium | 19 браузерных сценариев и контейнер группы; реальные HTML/JS/DOM, подменены controller/storage/HTTP; доверенные действия через CDP |
| `python -m unittest discover -s tests -p test_cloud_build.py` | exit 0; 6 тестов, OK |
| `python tools/build_common.py`, два последовательных запуска | exit 0 оба раза; SHA-256 совпадает |
| ZIP integrity и inventory | CRC без ошибок; 92 записи, 91 исходный файл совпадает с текущей extension/ и своим SHA-256 в inventory |
| Manifest и прежние пользовательские правки | manifest побайтно совпадает с HEAD; все 9 ранее изменённых файлов совпадают с сохранёнными контрольными суммами |
| `git -c core.whitespace=cr-at-eol diff --check` | exit 0; исходные CRLF у extension/** сохранены, как требует отключённая нормализация этой папки |
| Независимое ревью | Замечания по циклам повторов, сохранению правок, чужим операциям и безопасному отказу исправлены; итоговых блокирующих замечаний нет |

Каждая исправленная ошибка сначала воспроизводилась падающим тестом.
Неопределённое сохранение, поздний результат, правильный и неправильный номер
карточки, пропавший ответ BEGIN/FINISH, несколько вкладок, смена диалога, повторная
заявка и безопасный ручной повтор проверяются отдельно. В режиме readOnly проверяются
не только POST, но и изменяющая статус нативная GET-ссылка.

## Локальный тестовый артефакт

`dist/Lead-Partner-Common-1.2.50.zip`, **519260 байт**.

SHA-256:

```text
f35ce01d9abdd100adfa5bfe3b066c4ddb794de691f83c1de47d302cfdeea956
```

Номер 1.2.50 оставлен намеренно: это локальный проверочный пакет, а не новый
публичный выпуск. Существующие архивы releases/ не заменялись. Сотрудникам ничего
не отправлялось; Git push, создание релиза и публикация окружения не выполнялись.

## Что не проверялось

Живые запросы CRM, настоящее создание/редактирование заявок, реальные браузерные
сессии сотрудников, Telegram, доступность внешних карт, Windows PowerShell и
GitHub Actions после этих изменений не запускались. Cloud workflow теперь включает
Node/Chrome-проверки, но его конфигурация не является доказательством успешного CI.
Перед выпуском остаются Windows-валидация точного пакета и ручная приёмка на
разрешённой тестовой CRM по сценарию из `reliability-audit.md`.

Рост временных контекстных кэшей на длинной сессии остаётся известным следующим
этапом; журналы незавершённых операций ради ограничения памяти не удаляются.
