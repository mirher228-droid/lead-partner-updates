## Воспроизведение

Из корня репозитория:

```bash
node --test
python -m unittest discover -s tests -p test_cloud_build.py
python tools/build_common.py
node tools/soak_common.cjs --duration-ms 18000000 --interval-ms 1500 --output ../reliability-runs/new-five-hour-run
```

Runner требует Node 22+ и Chromium/Chrome; путь можно задать через CHROMIUM_PATH.
Новый запуск должен использовать новую папку результатов. Пятиминутный или
ускоренный диагностический запуск не является пятичасовым. Изменение замороженных
исходников, отмена, ошибка или отсутствие доказанного прогрева запрещают
пятичасовой passed. Внешние запросы заблокированы, данные искусственные.

После завершения длительного прогона снова выполнены **180 Node-проверок и
6 Python-тестов**: все прошли, без пропусков и отмен. Сборка повторно завершилась
успешно. Разнесённые по времени сборки дали один SHA-256.

## Практические пределы

Passed относится к этому искусственному сценарию и заданным ограничениям,
а не к отсутствию любых утечек или ошибок. Браузер использовал реальные модули
панели с искусственным controller/storage; настоящий controller/gate проверялся
отдельно с искусственным CRM-сервисом. Непустые долговременные журналы покрыты
профильными регрессиями. Живая CRM, Windows-обновлятор, Telegram и новый запуск
GitHub Actions после изменений не проверялись. Перед отдельной командой на выпуск
нужны Windows-валидация точного пакета и приёмка на разрешённой тестовой CRM.
