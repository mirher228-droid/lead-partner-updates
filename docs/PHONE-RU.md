# Исправления с телефона

Репозиторий: mirher228-droid/lead-partner-updates. Исходники старой общей панели: extension/. Исходная версия: 1.2.50. Новая тестовая версия сотрудников и ТГ чатеры сюда не перенесены.

В ChatGPT откройте Codex / режим работы с кодом, выберите облачное окружение с этим репозиторием. Задачу запускайте в облаке, а не на рабочем компьютере.

Пример задания:
> В старой общей панели Авито ошибка: [описание и скриншот]. Исправь минимально, сохрани текущие функции и идентификатор расширения. Прочитай AGENTS.md. Проведи проверки и подготовь тестовую сборку. Пока не выпускай обновление сотрудникам.

Проверки: `python -m unittest discover -s tests -p test_cloud_build.py`, затем `python tools/build_common.py`. Нужны Python 3 и Node.js, дополнительных библиотек нет. Windows-проверки выполняются в GitHub Actions. Собранный ZIP доступен в завершённом запуске Build Common from editable sources → Artifacts → common-test-build. Это тестовый файл, он не обновляет сотрудников сам.

После проверки можно дать отдельное задание:
> Выпусти проверенное исправление старой общей версии сотрудникам через существующий common-канал. Увеличь версию, дождись всех проверок, проверь update.json и дай ссылку на выпуск.

Существующий Windows-обновлятор скачивает обновления в фоне; применение требует полного завершения браузера, включая фоновые процессы. Рабочий компьютер владельца для облачных задач не нужен. Компьютеры сотрудников должны быть включены и подключены к интернету, чтобы скачать обновление. Реальные базы и авторизованные браузеры офисного ПК облаку автоматически не доступны: интеграционные проверки нельзя объявлять выполненными только по сборке.
