Lead-Partner · Общая 1.2.10
Подбор работ и услуг по комментарию · 24.10.2026

Постоянная папка обновлена. В chrome://extensions нажмите ↻ у установленного расширения, затем обновите LeadChat. Не удаляйте существующую установку.

Перенесён полный словарь crm-updates: КП — 47 ключей; МНЧ — 151; БТ — 36. Добавлены однозначные сокращения из его интерфейса. Прежние дополнительные правила сохранены там, где они не конфликтуют со справочником.

Примеры:
— МНЧ: «нужно заменить розетки» → Электрика → Розетки/Выключатели.
— МНЧ: «кран» → Сантехника → Смесители/Сифоны.
— МНЧ: «подключить стиралку» → Электрика → Подключение бытовой техники.
— МНЧ: «ПВХ окно» → Мелкие работы → Пластиковые окна.
— КП: «ноутбук», «комп», «PlayStation» → соответствующий вид техники.
— БТ: «холодильник», «хд», «стиралка» → соответствующий вид техники.

Ручной выбор вида работ или услуг сохраняется. При выбранном вручную виде работ комментарий может заполнить только совместимую услугу. Открытие сохранённой заявки само по себе не меняет её категории; подбор включается при редактировании комментария.

Выбираются только доступные варианты из текущих списков CRM. Если названия нет или оно неоднозначно, расширение оставляет выбор оператору. Для КП и БТ в референсе нет словаря нативных услуг: текстовые заготовки не выдаются за реальные услуги CRM.

Привязка Google-каталога, настройки, вход в Telegram и остальные функции не изменялись. Автоматическая отправка сообщений или создание заявки от ввода ключевого слова не выполняются.
